# Shooting state row colors

Updated Overview row colouring so the row background represents only the shooting state:

- waiting: grey
- active: yellow
- finished: light green

Qualification/progression state (qualified direct, R2, KO, Shoot-off, eliminated) is kept as the badge in the right-hand status column and no longer determines the row background.

The active score-entry cursor remains red/pink so the current input location is still obvious.
