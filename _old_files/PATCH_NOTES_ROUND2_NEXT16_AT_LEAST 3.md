# Round 2 selection logic — next N, at least

แก้ความหมายของค่ารอบ 2 ให้ตรงกติกา FIPJP:

- ค่า 16 หมายถึง "ผู้เล่นถัดจากผู้ผ่านตรงอย่างน้อย 16 คน" ไม่ใช่ "ถึงอันดับที่ 16"
- ตัดผู้ผ่านตรงออกก่อน
- เลือกผู้เล่นถัดมา N คน
- ดู TOTAL ของผู้เล่นคนที่ N ในกลุ่มรอบ 2
- รับผู้เล่นถัดไปทุกคนที่มี TOTAL เท่ากับคนนั้นเพิ่มเข้ารอบ 2
- Manual Round 2 Override ยังสามารถปิดรายคนได้ภายหลังโดยไม่แก้คะแนน/อันดับ
- Cut line ใช้กลุ่ม candidate จริงหลัง logic ใหม่นี้

เพื่อไม่ให้ PostgreSQL เดิมต้อง migrate ยังคงใช้คอลัมน์ `round_two_cutoff_rank` ภายในฐานข้อมูล แต่ UI และ logic เปลี่ยนความหมายเป็นจำนวนผู้เล่นขั้นต่ำของรอบ 2 แล้ว
